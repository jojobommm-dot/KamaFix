# KamaFix — сайт сервиса по ремонту телефонов

Статический сайт (HTML + CSS + JS, без сборки), свёрстан по макету Figma
[«KamaFix — шаблон сайта»](https://www.figma.com/design/eh0FahYJg2MoJfaMRm2YFp).

Страницы: `index.html` (Главная), `services.html` (Услуги и цены),
`calculator.html` (Калькулятор), `contacts.html` (Контакты).

## Как считается цена

**Итого = средняя цена запчасти + работа мастера.**

Все цены лежат в `data/prices.json`. Для каждой модели, ремонта и качества
запчасти там хранится список предложений поставщиков. Сайт сам:

1. отбрасывает аномально дешёвые и дорогие предложения (правило 1,5 × IQR),
2. считает среднюю по оставшимся и округляет до 10 ₽,
3. прибавляет фиксированную стоимость работы (`labor`).

Логика — в `assets/js/pricing.js`.

### Формат `data/prices.json` (контракт для парсера)

```jsonc
{
  "updatedAt": "2026-10-31T09:00:00+03:00",   // когда парсер обновил цены
  "suppliers": ["Поставщик 1", "..."],
  "repairs":   { "screen": { "name": "Замена экрана", "problem": "Разбит экран" }, ... },
  "qualities": { "original": { "name": "Оригинал", "note": "Как с завода, гарантия 90 дней" }, ... },
  "models": [
    {
      "id": "iphone-13", "brand": "Apple", "name": "iPhone 13",
      "repairs": {
        "screen": {
          "labor": 1500,              // работа мастера, ₽
          "duration": "1 час",
          "parts": {                  // качество -> предложения поставщиков
            "original": [ { "supplier": "Поставщик 1", "price": 6300 } ],
            "oled":     [ ... ],
            "econom":   [ ... ]
          }
        },
        "water": { "labor": 1500, "duration": "1 день", "parts": {} }  // без запчасти
      }
    }
  ]
}
```

Парсеру достаточно перезаписывать этот файл (например, раз в сутки). Сейчас
там **пример данных**, сгенерированный `scripts/make_sample_prices.py`.
Стоимость работы, адрес, телефоны — тоже заглушки из макета.

## Запуск локально

Цены загружаются через `fetch`, поэтому открывать файлы двойным кликом нельзя —
нужен любой локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Подойдёт любой статический хостинг: GitHub Pages, Netlify, nginx.
